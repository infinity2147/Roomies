# Methodology review (red team) — 2026-10-02

Reviewer scope: evaluation validity, statistics, leakage, SFT data, agent-eval hygiene. Read-only except this
file and throwaway checks in `src/analysis/review/` (`pilot_table.py`, `env_leak.py`, `kaggle_env_p2p.py`,
`tool_err.py`, `graph_commit_check.py`, `b1_insert_check.py`, `sft_segment_check.py`, `locate_recheck.py`).
**F** = fact (command/file evidence), **H** = hypothesis.

## Headline

1. **The Kaggle eval kernel does not run the agent's patch for `src/`-layout repos (requests, httpx).** On Kaggle the
   subprocess sandbox inherits the notebook image's `dist-packages` and only puts `/workspace` on `PYTHONPATH`, and
   `install_test_dependencies` is a no-op there. As a result `import requests` loads `/usr/local/lib/python3.12/dist-packages/requests`,
   not `/workspace/src/requests`. So 9 requests + 1 httpx = **10 of the 107 valid tasks (9.3 %) can never be solved
   in any Kaggle run**. The agent's own test runs there also check the wrong code. Kaggle is also Python 3.12, while
   the scorer image and our local env are 3.13. The Kaggle numbers are therefore measured in a **third environment**
   that matches neither local nor the hidden scorer.
2. **We do not know whether gold patches pass in the Kaggle env, and we do not know the hidden env at all.** The valid
   set was built only under our local per-task pip resolution. The cheapest way to settle this is a CPU-only Kaggle
   kernel that runs gold and empty patches.
3. **`tool_err_rate` mostly counts `grep` finding nothing:** 376 of 446 "errors" in C6a (84 %). The real error rate is
   about 3.6 %, not 23 %.
4. **The pass@8 = 0.467 "headroom" is a cross-configuration oracle, not pass@k of one policy.** The premise for RFT
   ("pass@k ≫ pass@1") still needs a same-config repeat measurement.
5. **SFT task attribution breaks once mined tasks are added.** There are 28 prefix collisions (for example "tweaks"
   appears twice). Also, 15 of 69 resolved patches carry junk or test edits that would be trained as "success".
